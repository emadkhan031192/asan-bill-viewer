
# Asan Bill Viewer - آسان بل ویور
Pakistani Bill Viewer All in One - 100% Official Source Only

## Features
- LESCO, GEPCO, FESCO, IESCO, MEPCO, PESCO, HESCO, SEPCO, QESCO, TESCO via bill.pitc.com.pk
- K-Electric via bill.ke.com.pk (13-digit A/C)
- SNGPL via bill.sngpl.com.pk, SSGC via viewbill.ssgc.com.pk
- PTCL via dbill.ptcl.net.pk, WASA via wasa.lahore.gop.pk
- ML Kit OCR Scan - point camera at printed bill
- Offline PDF Vault - Scoped Storage compliant
- Trust Badge: Data from official domain
- <15MB APK

## Build APK via GitHub
1. Push this repo to GitHub
2. Go to Actions tab -> Build Asan Bill Viewer APK -> Run
3. Download APK from Artifacts or Releases

```bash
flutter pub get
flutter build apk --release
```
